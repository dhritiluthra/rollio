**The problem with showing map directly:**

- User lands on a full screen map with no context
- They don't know what's nearby before they even search
- Map feels overwhelming as a first screen
- Forces the user to zoom/pan before they find anything useful

---

**Your flow is cleaner:**

```
/map page loads
      ↓
Clean search screen — "What are you craving?"
Search bar + filter options (radius, category)
      ↓
User types "chaat" or "momos", hits enter
      ↓
Results page — toggle between List and Map view
List view is default (less overwhelming)
Map view on demand
```

This is exactly how good apps work — **Zomato shows list first, map is optional**. Swiggy same. The map is a power feature, not the landing experience.
